# Source 05：章節推進、隱藏曲解鎖與課題模式

## 1. 章節結構與收集品
- 遊戲分為「主線章節」（如第五章《霓虹燈牌》、第六章《方舟》、第七章《時鐘塔》、第八章《凌日潮汐》等）與「支線／單曲精選集」。
- 遊玩曲目可獲得虛擬貨幣 **Data（KB / MB / GB）**，可用於在商店解鎖單曲、頭像與背景插畫。

## 2. 隱藏魔王曲解鎖機制
Phigros 的主線高潮通常伴隨極具儀式感的「隱藏曲解鎖演出」（異象觸發）：
- 例如知名魔王曲《Igallta》、《Rrhar'il》、《Distorted Fate》等，需要玩家在特定曲目達成指定條件（如特定分數、不按特定假鍵、或連續通關前置曲目），畫面會觸發劇情動畫並直接進入隱藏曲的初見挑戰。

## 3. 課題模式（Challenge Mode）
- **解鎖條件**：通關主線任意一首曲目後即可在主選單開啟課題模式。
- **核心規則**：玩家需自選並連續挑戰 **3 首不同曲目**，且判定區間大幅收緊（Perfect 判定從一般模式的 ±80ms 縮減一半為 **±40ms**），考驗極限準度與穩定度。
- **段位計算規則（數字看等級總和、顏色看三首總分）**：
  - **徽章數字**：將 3 首挑戰曲目的難度等級數字相加。
  - **徽章顏色（依三首總分判定，三首總滿分 3,000,000 分）**：
    - **彩色（彩虹）**：**3,000,000 滿分**（平均 100 萬，三首皆 AP）
    - **金色（黃色）**：**2,940,000 分以上**（平均 98 萬+）
    - **紅色**：**2,850,000 分以上**（平均 95 萬+）
    - **藍色**：**2,700,000 分以上**（平均 90 萬+）
    - **綠色**：**2,460,000 分以上**（平均 82 萬+）
    - **挑戰失敗**：**低於 2,460,000 分**不會獲得徽章，結算後直接返回選曲頁面。
